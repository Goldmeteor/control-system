# Learning Hub

12 周双主线学习管理网站，整合路径规划科研路线、软件工程清单和备案与资质流程。

## 功能

- 总览仪表盘：任务总数、完成进度、模块入口
- 12 周双主线：第 1-8 周科研主线 + 软件工程副线，第 9-12 周软件工程主线
- 软件工程清单：专业地基、Web 全栈、部署安全、备案合规、工程素养
- 备案与资质：ICP 备案、ICP 许可证、EDI、ISP、公安联网备案完整流程
- 数据管理：localStorage 保存进度，支持 JSON 导入导出

## 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Lucide

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
